# Remote API img2img helper

**Remote API img2img helper** — скрипт для Adobe Photoshop, который передаёт выделенную область удалённому API генерации изображений, получает результат и размещает его в документе отдельным слоем с маской.

Скрипт предназначен для работы в режиме **img2img непосредственно из Photoshop**: пользователь выбирает область изображения, настраивает модель и параметры запроса, после чего результат автоматически возвращается в документ без ручного экспорта и импорта файлов.

Текущая версия JSX-скрипта и Python API: `0.1`.

## Возможности

- генерация через NeuroAPI, BotHub и GenAPI;
- отдельные настройки и промпт для каждой модели;
- выбор поддерживаемых моделью пропорций, качества или разрешения;
- автоматический и ручной ресайз входного изображения;
- один дополнительный файл-референс для совместимых моделей;
- библиотека пресетов промпта;
- перевод промпта на английский язык;
- размещение результата как Smart Object с маской исходного выделения;
- сохранение параметров в Photoshop Actions;
- тихий запуск с последней моделью и её настройками;
- восстановление параметров из метаданных созданного слоя;
- шифрование API-ключей средствами Windows DPAPI;
- автоматическая установка необходимых Python-модулей.

## Требования

- Windows;
- Adobe Photoshop CC 2014 или новее;
- документ Photoshop в режиме RGB;
- Python 3.9 или новее;
- интернет-соединение;
- API-ключ и доступный баланс у выбранного провайдера.

Во время установки Python рекомендуется включить параметр **Add Python to PATH**. Файлы `.pyw` должны быть связаны с установленным Python.

## Установка

Рекомендуемая структура файлов:

```text
Photoshop\Presets\Scripts\
├── Remote API img2img helper.jsx
├── README.md
└── lib\
    ├── api-img2img.pyw
    └── cards\
        ├── providers\
        │   ├── bothub.json
        │   ├── genapi.json
        │   └── neuroapi.json
        └── models\
            ├── bothub\
            ├── genapi\
            └── neuroapi\
```

1. Установите Python 3.9 или новее.
2. Скопируйте содержимое архива в каталог Photoshop `Presets\Scripts` либо оставьте проект в другой постоянной папке.
3. Перезапустите Photoshop, если файлы были помещены в `Presets\Scripts`.
4. Запустите скрипт:

```text
File → Scripts → Remote API img2img helper
```

или выберите JSX вручную:

```text
File → Scripts → Browse…
```

Файл `api-img2img.pyw` и каталог `cards` рекомендуется хранить вместе в подпапке `lib`. Также поддерживается плоская структура, в которой оба элемента находятся рядом с `Remote API img2img helper.jsx`:

```text
Remote API img2img helper.jsx
api-img2img.pyw
cards\
README.md
```

Не разделяйте Python API и каталог карточек между разными произвольными папками. Если одновременно существуют копии `api-img2img.pyw` рядом с JSX и в `lib`, скрипт использует версию из `lib`.

При первом запуске Python автоматически установит недостающие модули `requests` и `Pillow`. При первом использовании перевода дополнительно устанавливается `deep-translator`. Установка может занять больше времени, чем обычный запуск.

## Быстрый старт

1. Откройте RGB-документ Photoshop.
2. Создайте выделение вокруг области, которую нужно обработать.
3. Запустите `Remote API img2img helper`.
4. Откройте общие настройки кнопкой `⚙`.
5. В строке нужного провайдера нажмите **Указать** и введите API-ключ.
6. Выберите провайдера и модель.
7. Введите промпт и настройте размер, пропорции, качество и референс.
8. Нажмите **Генерировать**.

Результат помещается в документ на слой:

```text
generated image
```

К слою добавляется маска исходного выделения. Если API вернул несколько изображений, Photoshop использует только первое.

Для повторной генерации той же области можно выбрать ранее созданный слой `generated image`. Скрипт использует его маску или прозрачность для восстановления рабочей области, когда это возможно.

## Промпты и пресеты

Промпт хранится **отдельно для каждой модели** вместе с её параметрами генерации.

Например, модели `GenAPI / GPT Image 2` и `NeuroAPI / GPT Image 2` имеют независимые профили и могут содержать разные промпты, пропорции, качество, масштаб и референс.

При переключении модели:

1. текущий текст сохраняется в профиль отображаемой модели;
2. в поле загружается промпт выбранной модели;
3. остальные параметры интерфейса восстанавливаются из того же профиля.

Библиотека пресетов промпта является глобальной и доступна для всех моделей.

| Кнопка | Действие |
|---|---|
| `↻` | очистить поле |
| `+` | создать пресет из текущего текста |
| `✔` | обновить выбранный пресет |
| `×` | удалить выбранный пресет |

Пресет по умолчанию нельзя удалить или перезаписать.

Кнопка перевода преобразует текущий промпт в английский язык. Для перевода требуется интернет-соединение.

## Размер входного изображения

Размер входного файла Photoshop и размер результата API — независимые параметры.

### Автоматический ресайз

При включённом **Auto resize** размер рассчитывается по выделению и выбранному resize-профилю. Профиль содержит:

- минимальную короткую сторону;
- строгое ограничение общей площади в мегапикселях.

В комплект входят три профиля:

| Профиль | Целевая короткая сторона | Максимальная площадь |
|---|---:|---:|
| `1K` | 1024 px | 1,1 MP |
| `2K` | 2048 px | 4,2 MP |
| `4K` | 4096 px | 16,8 MP |

Для квадратного выделения значения соответствуют номинальным размерам 1024×1024, 2048×2048 и 4096×4096. Для широких и портретных пропорций короткая сторона может быть меньше целевого значения. Ограничение площади применяется строго: если достижение целевой стороны превысит лимит, приоритет получает максимальная площадь.

Скрипт сохраняет пропорции выделения и подбирает коэффициент так, чтобы входное изображение не превышало лимит профиля. Автоматическое увеличение ограничено коэффициентом `8×`.

Ползунок можно вручную сдвинуть и при включённом **Auto resize**. В этом случае установленный коэффициент сохраняется в профиле модели и используется при последующих тихих запусках. При следующем показе главного окна временная поправка сбрасывается, после чего размер снова рассчитывается по актуальному выделению и выбранному resize-профилю.

В общих настройках встроенные resize-профили можно изменять, а также создавать собственные. После сохранения окна настроек список и значения профилей сразу обновляются в главном окне; выбранный провайдер, модель, промпт и остальные параметры текущего профиля при этом не сбрасываются.

### Ручной ресайз

Если автоматический режим выключен, коэффициент масштаба задаётся вручную. Значение хранится отдельно в профиле текущей модели.

## Пропорции и качество результата

Элементы управления отображаются только тогда, когда они описаны в карточке модели.

Для пропорций доступны три типа значений:

- **Авто** — скрипт выбирает ближайшее поддерживаемое соотношение к текущему выделению;
- **По выделению** — параметр пропорций или размера результата не отправляется, и API получает исходное изображение без дополнительного ограничения;
- конкретное соотношение или размер — в API передаётся выбранное значение, например `1:1`, `16:9` или `1024x1536`.

Параметр качества может называться **Quality**, **Resolution** или не отображаться вовсе — это зависит от модели. Скрипт не создаёт дополнительные значения и показывает только варианты, указанные в карточке.

Фактический размер возвращённого файла может отличаться от выбранного номинального значения, если провайдер или модель обрабатывает его иначе.

## Референсное изображение

Совместимые модели позволяют добавить один дополнительный файл-референс.

Поддерживаемые форматы:

```text
jpg, jpeg, png, webp
```

Недавно выбранные файлы сохраняются в общей истории. Отсутствующие или неподдерживаемые файлы удаляются из неё автоматически.

Референс отправляется как дополнительное изображение вместе с основной областью Photoshop. То, как именно модель использует его, определяется реализацией выбранного API.

## Общие настройки

Кнопка `⚙` открывает настройки скрипта.

В них доступны:

- API-ключи провайдеров;
- библиотека resize-профилей;
- объединение видимых слоёв перед отправкой;
- растеризация созданного результата;
- сохранение пропорций при размещении;
- активация кисти после генерации;
- непрозрачность кисти;
- таймаут генерации;
- запись параметров в Photoshop Actions;
- сохранение параметров в метаданные слоя.

### Объединение слоёв перед отправкой

При включённой настройке входное изображение формируется из видимого результата документа. При выключенной используется обычная логика подготовки области относительно активного слоя и расположенных над ним слоёв.

### Размещение результата

По умолчанию результат растягивается точно до границ выделения.

При включённом **Сохранять пропорции при размещении** изображение пропорционально вписывается внутрь выделенной области. Скрипт не использует режим cover и не обрезает результат автоматически.

Если включена растеризация, созданный Smart Object преобразуется в обычный пиксельный слой после размещения.

## Метаданные и Photoshop Actions

### Метаданные слоя

При включённой записи метаданных созданный слой содержит:

- провайдера;
- модель;
- промпт;
- профиль модели;
- размеры входного и фактически полученного изображения;
- удалённый идентификатор запроса, если провайдер его возвращает.

API-ключ в метаданные не записывается.

Если активный слой содержит совместимые данные, в верхней части главного окна появляется кнопка **LOAD**. Она восстанавливает провайдера, модель, промпт и параметры профиля.

### Photoshop Actions

Параметр **Записывать настройки в экшен** определяет источник модельных параметров при воспроизведении Action.

#### Параметр выключен

В Action записывается только служебный маркер. При воспроизведении используются актуальные данные из файла `Remote API img2img helper.desc`:

- последний выбранный провайдер и модель;
- профиль модели;
- все глобальные настройки;
- API-ключи;
- библиотеки пресетов.

Такой Action всегда работает с последними настройками пользователя.

#### Параметр включён

В Action записываются только:

- выбранный провайдер;
- выбранная модель;
- профиль выбранной модели.

Профиль содержит:

```text
prompt
autoResize
resizePreset
resize
resizeDirty
manualScale
aspectRatio
quality
reference
```

`resizeDirty` отмечает временную ручную поправку ползунка в автоматическом режиме. Она действует в тихом запуске до следующего показа главного окна.

Все глобальные данные в любом случае загружаются из актуального `DESC`:

- API-ключи;
- prompt-пресеты;
- resize-пресеты;
- параметры подготовки и размещения изображения;
- настройки кисти;
- таймаут;
- запись метаданных и другие общие параметры.

Если модель или провайдер, записанные в Action, были удалены из каталога, скрипт завершает запуск явной ошибкой и не подставляет другую модель. Такой шаг Action необходимо записать заново.

Показ главного окна при воспроизведении управляется стандартным переключателем диалога у шага Photoshop Action.

## Тихий режим

После успешного запуска из главного окна следующий обычный запуск может выполняться без диалога.

В обычном тихом режиме скрипт использует из `DESC`:

- последнего провайдера;
- последнюю модель;
- её профиль и промпт;
- сохранённую ручную поправку Auto resize, если ползунок изменялся в последнем показанном окне;
- глобальные настройки и API-ключ.

Если модель из обычного `DESC` больше недоступна, скрипт выбирает первую доступную модель, отменяет тихий запуск и показывает интерфейс перед генерацией.

При тихом воспроизведении Action с записанными параметрами используется модель из Action. Если она отсутствует, генерация не начинается и выводится ошибка.

Интерфейс принудительно открывается:

- после отмены или ошибки;
- при отсутствии API-ключа;
- при изменении или недоступности обычной сохранённой модели;
- при запуске с включённым диалогом у шага Action;
- при удерживании `Shift` во время обычного запуска.

## Карточки провайдеров и моделей

Каталог `cards` является обязательной частью проекта. В рекомендуемой структуре он находится в `lib` рядом с Python API:

```text
lib\
├── api-img2img.pyw
└── cards\
    ├── providers\
    │   └── <provider>.json
    └── models\
        └── <provider>\
            └── <model>.json
```

При плоской установке допустим путь `cards` рядом с JSX и `api-img2img.pyw`.

Карточка провайдера определяет:

- базовый URL;
- способ авторизации;
- маршрут запроса;
- используемый API-адаптер.

Карточка модели определяет:

- идентификатор и название модели;
- поддержку референса;
- список пропорций или размеров;
- список значений качества или разрешения;
- постоянные поля запроса.

Скрипт проверяет карточки при запуске. Файл с ошибочной структурой пропускается, а сообщение отображается пользователю.

Пользовательский каталог карточек и редактор карточек в интерфейсе версии `0.1` не предусмотрены.

## Хранение настроек и безопасность

Основные настройки сохраняются в бинарный `ActionDescriptor`:

```text
Remote API img2img helper.desc
```

Файл находится в каталоге настроек Photoshop.

В `DESC` хранятся:

- последний выбранный провайдер и модель;
- отдельный профиль каждой модели;
- глобальные настройки;
- prompt- и resize-пресеты;
- история референсов;
- зашифрованные API-ключи.

Запись выполняется через временный файл с проверкой чтения и резервной копией `.bak`.

API-ключ:

- шифруется Windows DPAPI;
- привязан к текущей учётной записи Windows;
- не хранится в открытом виде;
- не записывается в Action;
- не записывается в XMP;
- не выводится в журнал.

Рабочие и временные файлы Python находятся в:

```text
%LOCALAPPDATA%\Remote API img2img helper\
```

Журнал:

```text
%LOCALAPPDATA%\Remote API img2img helper\remote-api-img2img.log
```

## Устранение проблем

### Скрипт отсутствует в меню Photoshop

Убедитесь, что `Remote API img2img helper.jsx` находится непосредственно в `Presets\Scripts`, затем перезапустите Photoshop. Также скрипт можно запустить через **File → Scripts → Browse…**.

### Python API не запускается

Проверьте:

- установлен ли Python 3.9 или новее;
- включён ли Python в `PATH`;
- связан ли тип файла `.pyw` с Python;
- находится ли `api-img2img.pyw` в подпапке `lib` или рядом с JSX;
- находится ли каталог `cards` рядом с найденным Python API;
- не блокирует ли запуск антивирус или политика Windows.

Подробности находятся в файле журнала.

### Первый запуск занимает много времени

При первом запуске могут устанавливаться `requests` и `Pillow`. При первом переводе устанавливается `deep-translator`. Дождитесь окончания процесса и не закрывайте Photoshop.

### Провайдер или модель отсутствуют в списке

Проверьте наличие соответствующих JSON-файлов в `lib\cards\providers` и `lib\cards\models`. При плоской установке используются `cards\providers` и `cards\models`. Ошибочная карточка пропускается, а причина выводится при открытии интерфейса.

### Action сообщает об отсутствующей модели

Записанная в Action модель была удалена или переименована. Откройте скрипт, выберите доступную модель и перезапишите шаг Action.

В обычном режиме недоступная модель автоматически заменяется первой доступной с обязательным показом интерфейса.

### Ошибка удалённого API

Проверьте:

- правильность API-ключа;
- баланс и лимиты аккаунта;
- доступность модели у провайдера;
- допустимость выбранных параметров;
- интернет-соединение;
- значение таймаута генерации.

При обращении за помощью приложите сообщение Photoshop и соответствующий фрагмент `remote-api-img2img.log`. Не публикуйте API-ключ.

## Ограничения

- поддерживается только Windows;
- скрипт работает только с RGB-документами;
- для генерации требуется внешняя платная или лимитированная API-служба;
- inpaint-маска и отдельный mask-параметр удалённому API не отправляются;
- поддерживается не более одного дополнительного референса;
- из нескольких результатов используется только первое изображение;
- фактическое соблюдение пропорций, качества и референса зависит от конкретной модели и провайдера;
- набор моделей определяется поставляемыми JSON-карточками;
- изменение API провайдера может потребовать обновления соответствующей карточки или адаптера.
